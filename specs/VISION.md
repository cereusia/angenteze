# Visao

## Identidade

Agente Ze e um assistente global para macOS, open source, inspirado na CereusIA, na resiliencia da Caatinga, no sertao e na ideia de transformar intencao em acao.

O projeto deve funcionar como operador local: entende uma intencao, consulta memoria, coordena ferramentas e executa tarefas com controle, auditoria e confirmacao quando houver risco.

## Missao

Criar uma base modular para um agente local de macOS baseado em:

- app SwiftUI/menu bar;
- nucleo Python local;
- memoria SQLite;
- ferramentas via MCP;
- agentes especialistas;
- documentacao versionavel;
- seguranca local-first.

## Principios

- Local-first antes de cloud-first.
- MCP-first para ferramentas.
- Documentacao antes de codigo.
- Permissoes explicitas para acoes sensiveis.
- Logs auditaveis.
- Dependencias minimas.
- Evolucao incremental.
- Decisoes tecnicas registradas em ADRs.

## Usuario Inicial

O primeiro usuario e um operador tecnico que usa macOS e Codex para coordenar projetos, arquivos, automacoes, memoria local e agentes especialistas.

## v0.1

O primeiro marco deve entregar apenas a base funcional minima:

- app de menu bar;
- hotkey global;
- prompt global;
- backend local;
- memoria local inicial;
- cliente MCP inicial.

## Fora do v0.1

- Voz.
- Browser embutido.
- Automacao ampla do sistema.
- Multiagente completo.
- Marketplace de ferramentas.
- Sincronizacao cloud.
- Extensoes publicas.
