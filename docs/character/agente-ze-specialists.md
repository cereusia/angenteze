# Agente Ze - Variacoes Futuras de Especialistas

## Regra Base

Todos os especialistas devem preservar:

- mesma silhueta-base;
- visor preto frontal;
- olhos luminosos;
- capuz/capacete mandacaru;
- proporcao chibi;
- postura amigavel;
- mochila tecnica.

As variacoes podem alterar apenas:

- acessorio principal;
- cor secundaria;
- simbolo pequeno;
- ferramenta visual nao agressiva.

## Regras de Publicacao

- Cada variacao deve ter manifest JSON proprio.
- Nao criar variacao que pareca arma, soldado ou personagem agressivo.
- Nao alterar a anatomia base sem ADR visual.
- Toda variacao deve funcionar em menu bar, painel e runtime 3D.
