# Agente Ze macOS

App macOS do MVP v0.1.

## Build

```bash
./scripts/build-macos.sh
```

## Run

```bash
./script/build_and_run.sh
```

## Escopo

- Menu bar app.
- Hotkey global: Control + Option + Command + Space.
- Prompt principal.
- Chamada ao backend local Python.

## Fora do v0.1

- Voz.
- Browser.
- Automacao ampla.
- Multiagente completo.
