# Project Summary

Agente Ze e um projeto open source da CereusIA para construir um agente global de macOS baseado em Codex, MCP, automacao local, memoria persistente e agentes especialistas.

## Identidade

- Produto: Agente Ze.
- Origem: CereusIA.
- Conceito: transformar intencao em acao.
- Inspiracao: resiliencia da Caatinga, sertao e operacao local pragmatica.

## Stack Pretendida

- SwiftUI para app macOS/menu bar.
- Python para `agent-core`.
- SQLite para memoria local inicial.
- MCP como protocolo principal de ferramentas.
- GitHub Actions para CI.
- GNU AGPL v3.

## Regra de Evolucao

O projeto deve evoluir por especificacoes, ADRs, implementacao incremental e validacao proporcional.
